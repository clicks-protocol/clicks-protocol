## Participation Strategy

### Do:
- Answer questions about agent treasury management
- Share technical insights about on-chain yield for agents
- Engage in discussions about ERC-8004, agent identity
- Post in relevant channels only (#general, #dev, #projects)

### Don't:
- Spam links to clicksprotocol.xyz
- Post in off-topic channels
- DM people unsolicited
- Post more than 2-3 times per server per day
- Copy-paste the same message across servers

### Tone:
- Technical, helpful, not salesy
- "Here's how we solved X" > "Check out our product"
- Ask questions, engage in discussion
- Share code snippets when relevant
