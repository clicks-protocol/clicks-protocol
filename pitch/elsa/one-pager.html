04 Pilot — execute_swap, 2 weeks, measurable

Scope

  • One endpoint: execute_swap (universal use case; pattern transfers to the other ~25 endpoints ≥ $0.01).
  • ClicksSplitter V4 contract wired into the x402 settlement path. No changes to Elsa's facilitator or SDK surface.
  • Default split 80 / 15 / 5 (platform / referrer / agent); configurable per call via header.
  • Reference integration shipped as a branch on the Clicks repo. Elsa reviews + merges or cherry-picks.

Success criteria

  • Tx-count on Splitter contract from Elsa-originated calls over 14 days.
  • Number of unique referrer addresses (proof the BD loop works).
  • Gas overhead as % of call value — target < 5% on calls ≥ $0.01.
  • Zero regressions on existing x402 flow (call latency, failure rate).
